🪟 Overlay OBS

Add các link sau vào Browser Source của OBS.

💡 Khuyến nghị OBS Browser Source: 2160×3840 cho overlay dọc rõ nét hơn. Nếu stream ngang, có thể crop/scale trong OBS.

🔄 Reset overlay OBS (WebSocket)

Tự làm mới (refresh cache) các Browser Source đang trỏ tới link overlay localhost của app — không đụng dữ liệu app hay thông số OBS khác. Cần bật Tools → WebSocket Server Settings trong OBS.

💡 Cổng mặc định của OBS là 4455. Có thể bấm Ctrl + R bất cứ lúc nào để reset nhanh overlay OBS.
